Проект представляет собой минимальный прототип эмулятора оболочки операционной системы на языке Python. На первом этапе реализован консольный интерфейс, поддерживающий ввод команд пользователя, обработку переменных окружения операционной системы.
В приглашении к вводу команд отображается имя виртуальной файловой системы (VFS).
Реализованы заглушки ls и cd, выводящие имя команды и переданные аргументы. Команда exit завершает работу эмулятора.
